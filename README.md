🌱**Plant Disease Detection using Machine Learning**

📌**Deskripsi Project**

Proyek ini bertujuan untuk mengembangkan sistem berbasis machine learning yang mampu mendeteksi kondisi kesehatan tanaman melalui citra daun. Sistem ini dirancang untuk membantu petani dalam mengidentifikasi penyakit tanaman secara cepat dan akurat, sehingga dapat meningkatkan efisiensi perawatan dan hasil produksi.

Model yang dikembangkan akan mengklasifikasikan gambar daun ke dalam kategori sehat atau berbagai jenis penyakit berdasarkan pola visual yang terdeteksi.

📊**Dataset**

Dataset yang digunakan dalam proyek ini berasal dari Kaggle:

👉 https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset

🧾 Deskripsi Dataset

Dataset PlantVillage merupakan dataset populer dalam bidang pertanian digital yang berisi lebih dari 54.000 gambar daun tanaman yang terdiri dari kondisi sehat dan terinfeksi penyakit. Dataset ini mencakup sekitar 38 kelas yang merepresentasikan kombinasi jenis tanaman dan penyakit.

Beberapa karakteristik dataset:

📷 Total data: ±54.000 gambar

🌿 Jumlah kelas: 38 kategori

🌱 Jenis tanaman: ±14 jenis (tomat, kentang, apel, dll)

🦠 Jenis penyakit: bakteri, virus, jamur, dan lainnya

✅ Tersedia juga kelas tanaman sehat

Dataset ini banyak digunakan sebagai benchmark dalam pengembangan model klasifikasi penyakit tanaman berbasis computer vision.
